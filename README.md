# 전세자금 대출 상담 한도 추정

손님 정보(소득, 순자산, 보증금, 주택 유형 등)를 입력하면 전세자금대출 19개 상품의 **예상 적격 여부와 예상 한도**를 보여주는 상담 보조용 웹 도구입니다. 한도는 신규 계약 기준입니다.

- 대상 상품: 신생아 특례 버팀목, 일반 버팀목전세, 신혼부부전용 버팀목, 청년전용 버팀목, 신혼부부전세론, 다둥이전세론, 주택신보 전세자금대출, 전세금안심대출, 우량주택전세론, 서울시 신혼부부·청년 임차보증금 이자지원 대출, 하나은행 고정금리 전세자금대출, 군간부 전세자금대출(기본), 하나 청년전세론, 목돈 안드는 행복전세, 하나 부분분할상환 전세론, 한사랑전세론, 충청남도·세종시 청년 임차보증금 이자지원 대출
- 계약 체결일에 따라 달라지는 한도(25.6.27, 25.9.7 기준)와 신청인 연령(생년월일 입력), 혼인신고일, 자녀 출생일 등을 반영합니다.
- 상품 카드를 누르면 특이사항과 한도 산출 과정, 징구 서류 목록(양식 이름)을 볼 수 있습니다.
- 인쇄용 상담 결과지와 결과 복사 기능이 있습니다.

## 사용 방법

`index.html` 파일 하나로 동작합니다. 설치가 필요 없고, 인터넷이 없어도 브라우저로 열면 됩니다. 입력한 정보는 브라우저 안에서만 계산되며 어디에도 전송하거나 저장하지 않습니다.

## 꼭 읽어 주세요

- 이 도구의 결과는 **예상치**입니다. 실제 대출 가능 여부, 한도, 금리는 권리관계, 시세와 감정, 개인신용평점, 보증기관 심사에 따라 달라집니다.
- 기준값은 2026.7 상품 비교표, 하나은행 상품공시, 주택도시기금과 서울시의 공식 안내(2026.11 확인)를 확인한 값과 별도 정리 자료를 옮긴 값을 함께 담고 있으며, **상품설명서와 약관 원문과의 대조는 끝나지 않았습니다.** 상담과 약정에 쓰기 전에 원문을 확인하세요.
- 전세금안심대출과 우량주택전세론은 "연소득 대비 이자 40% 이내" 소득 한도를 계산합니다(기존 대출 잔액·금리 입력). 주택신보 계열(주택신보, 행복전세, 부분분할상환, 청년전세론, 충남·세종 청년)은 HF 상환능력별 보증한도(연간인정소득 − 부채상환 예상액)를 반영합니다. DSR은 계산하지 않고 대상 여부만 안내하며, 신용점수는 반영하지 않습니다.
- 화면 하단의 "기준 정보 및 변경 이력"에서 기준일과 참고한 자료를 확인할 수 있습니다.
- 징구 서류 목록은 서류 이름, 서식번호, 필수 여부, 대상만 담고 있으며 양식 파일은 포함하지 않습니다.

## 지원 브라우저

최신 Microsoft Edge, Chrome, Safari에서 동작하며, 구형 Edge(EdgeHTML)에서도 동작하도록 만들었습니다. Internet Explorer는 지원하지 않습니다.
